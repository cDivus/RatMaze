# A* Rat Maze

An interactive browser visualizer for A* pathfinding. Move the rat through the maze manually or watch A* search for the goal while comparing each candidate node.

## Run locally

Serve the project through a local web server:

```bash
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in a browser.
